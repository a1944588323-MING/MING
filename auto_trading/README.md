# A 股做 T 半自动化交易系统

## ⚠️ 法律声明 (必读)

A 股**禁止 1 万散户账户全自动量化下单**，必须满足:
- 50 万本金 + 2 年经验
- 通过券商 QMT/Ptrade 报备的程序化账户

**本系统采用"半自动化"** - 程序生成信号 + 你 1 秒手动下单, 完全合法。

## 这套系统能做什么

| 功能 | 自动化程度 |
|---|---|
| 实时数据拉取 | 100% 自动 (每分钟) |
| 信号生成 | 100% 自动 |
| 通知推送 | 100% 自动 (微信+桌面+响铃) |
| 下单 | **手动 1 秒确认** |
| 交易记录 | 100% 自动 (CSV) |
| 月度统计 | 100% 自动 |

## 部署 (5 分钟)

### 1. 安装依赖
```bash
pip install akshare pandas requests plyer openpyxl
```

### 2. 申请微信推送 (免费)
访问 https://sct.ftqq.com/ 用 GitHub 登录, 复制 SendKey

### 3. 编辑 config.py
```python
STOCK_CODE = "300059"
CAPITAL = 10000
SERVERCHAN_KEY = "你的Key"
```

### 4. 运行
```bash
python main.py
```
